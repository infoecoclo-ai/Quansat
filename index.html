Cài đặt

Cách kết nối với Google Sheet:
  1. Mở Google Sheet của bạn → Tiện ích mở rộng → Apps Script
  2. Xoá code mẫu, dán đoạn script được cung cấp riêng (file .gs)
  3. Bấm Triển khai → Triển khai mới → Web app
  4. Chọn quyền truy cập: Bất kỳ ai (Anyone)
  5. Bấm Triển khai, cấp quyền, rồi copy URL kết thúc bằng /exec
  6. Dán URL đó vào ô phía trên và bấm Lưu URL
